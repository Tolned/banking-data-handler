# 🏦 Banking Data Handler

**Интеллектуальная система для комплексного анализа, фильтрации, конвертации,
парсинга и логирования банковских транзакций.**

Разработано в рамках профильного курса по бэкенд-разработке от **Skypro**.

---

## 🛠️ Технологический стек

* **Язык программирования:** Python 3.12+
* **Пакетный менеджер:** Poetry
* **Тестирование:** Pytest, Pytest-Mock, Pytest-Cov
* **Аналитика и парсинг:** Pandas, OpenPyXL, CSV
* **Работа со строками и API:** Regular Expressions (`re`), Requests,
  Python-Dotenv
* **Качество кода:** Flake8, Black, Isort, Mypy

---

## 🚀 Архитектура и функциональные модули

### 🛡️ 1. Маскирование и виджеты (`src/masks.py`, `src/widget.py`)

Обеспечивает защиту конфиденциальных платежных реквизитов клиента и
форматирование дат:

* `get_mask_card_number` — маскирует номер банковской карты в формате
  `XXXX XX** **** XXXX`.
* `get_mask_account_number` — скрывает номер банковского счета до формата
  `**XXXX`.
* `mask_account_card` — автоматически распознает тип реквизита (карта или счет)
  и применяет нужную маску.
* `get_date` — преобразует дату и время из ISO-формата в читаемый вид
  `ДД.ММ.ГГГГ`.

### ⚙️ 2. Фильтрация, сортировка и статистика

Модули: `src/processing.py`, `src/regular_expressions.py`,
`src/counting_categories.py`.

* `filter_by_state` — отбирает банковские операции по статусу (`EXECUTED`,
  `CANCELED`, `PENDING`).
* `sort_by_date` — упорядочивает транзакции по дате (по возрастанию или
  убыванию).
* `filter_operations_by_description` — регистронезависимый поиск операций по
  ключевым словам с экранированием спецсимволов (`re`).
* `count_operations_by_category` — подсчет количества транзакций по заданным
  категориям на базе `collections.Counter`.

### 🔍 3. Потоковая обработка и генераторы (`src/generators.py`)

Оптимизированный инструмент для работы с большими массивами финансовых данных
без перегрузки оперативной памяти:

* `filter_by_currency` — ленивый итератор, динамически фильтрующий транзакции
  по коду валюты (`USD`, `RUB`, `EUR`).
* `transaction_descriptions` — генератор текстовых описаний для каждой
  банковской операции.
* `card_number_generator` — генератор номеров карт в заданном диапазоне в
  формате `XXXX XXXX XXXX XXXX`.

### 📊 4. Загрузка данных и конвертация валют

Модули: `src/utils.py`, `src/pandas_library.py`, `src/external_api.py`.

* **JSON-парсер:** безопасное чтение и валидация транзакций из `.json` с
  записью событий в `logs/utils.log`.
* **CSV и Excel парсеры:** считывание реестров операций из таблиц `.csv` и
  `.xlsx` с помощью **Pandas**.
* **Конвертер валют:** перевод сумм из `USD` и `EUR` в рубли (`RUB`) по
  актуальному курсу через Exchangerates Data API.

### 📝 5. Декоратор автоматического контроля (`src/decorators.py`)

* `@log` — параметризованный декоратор для трекинга работы функций. Фиксирует
  успешное выполнение или тип возникшей ошибки вместе с переданными
  аргументами.
* **Гибкий вывод:** поддерживает запись как в консоль (`stdout`), так и в
  локальный файл при передаче параметра `filename`.

## 🧪 Тестирование и контроль качества кода

Проект покрыт модульными тестами с использованием фикстур, параметризации и
мок-объектов (`unittest.mock`, `pytest-mock`).

```bash
# Запуск всех тестов с отчетом о покрытии кода
poetry run pytest --cov=src --cov-report=term-missing

# Проверка стиля кода (PEP 8) и строгой типизации
poetry run flake8
poetry run mypy src tests

# Автоматическое форматирование кода и импортов
poetry run isort .
poetry run black .
```

## 💻 Инструкция по развертыванию и запуску

### 1. Клонирование репозитория

```bash
git clone https://github.com<ваш-никнейм>/banking-data-handler.git
cd banking-data-handler
```

### 2. Установка зависимостей через Poetry

```bash
poetry install
```

### 3. Настройка переменных окружения

Создайте файл `.env` в корне проекта (по образцу `.env.example`) и укажите ваш
API-ключ для конвертации валют:

```env
EXCHANGE_API_KEY=ваш_ключ_от_apilayer
```

### 4. Запуск приложения

```bash
poetry run python src/main.py
```
